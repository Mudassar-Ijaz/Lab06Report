## Lab Task 06 — Abstract Data Types (ADT)


## Objective

The main objective of this lab is to understand Abstract Data Types (ADT) in Java. In this lab, I practiced using interfaces, abstraction, and encapsulation by creating different simple ADTs and their implementations.

## What I Implemented

In this lab, I completed the following tasks:

- **Lab Task 01:** Created a `Stack` interface and implemented it using an array in the `ArrayStack` class. I also tested the push and pop operations.
- **Lab Task 02:** Created a `Student` class to demonstrate encapsulation. The student data is kept private and accessed using getter methods.
- **Lab Task 03:** Used the `List` interface with `ArrayList` and `LinkedList` to demonstrate programming to an abstraction.
- **Homework 01:** Created a Library System using an interface and an implementation class. It supports adding, removing, searching, issuing, and returning books.
- **Homework 02:** Created a Student Management System using an interface and an `ArrayList`. I also created JUnit 5 tests to check its operations.
